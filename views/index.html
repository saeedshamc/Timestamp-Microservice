Timestamp Microservice

Send a date or a Unix timestamp, get both formats back as JSON.

Try it

Leave the field empty to get the current time.

Example usage

  • [project_url]/api/2015-12-25
  • [project_url]/api/1451001600000
  • [project_url]/api/

Example output

{"unix": 1451001600000, "utc": "Fri, 25 Dec 2015 00:00:00 GMT"}

An invalid date returns {"error": "Invalid Date"}.
